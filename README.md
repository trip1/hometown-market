# Hometown Market

A cross-platform hometown marketplace MVP for cash and barter listings.

## MVP now
- Public browsing without a login
- Cash, cash-only, trade, and trade-only offer types
- Local demo sign-in gate before posting
- Android debug APK and browser/Wasm build

## Next production slice
A real backend is required for cross-device accounts, durable listings, and private image object storage. The current browser deployment is an interactive MVP using local in-memory state.
